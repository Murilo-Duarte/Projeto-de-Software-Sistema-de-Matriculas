# Lab01S02 - Projeto Estrutural

## Objetivo

Entrega referente ao item 4.2 do laboratório: correção dos diagramas desenvolvidos, criação do diagrama de classes e criação do projeto Java com classes, atributos e stubs dos métodos modelados.

## Entregas realizadas

- Diagrama de classes do Sistema de Matrículas.
- Correção complementar do diagrama de casos de uso sem remover o arquivo original da Sprint 1.
- Projeto Java estruturado no padrão `src/main/java`.
- Classes de domínio, serviços, integração externa e exceções.
- Atributos e métodos principais modelados conforme os requisitos do laboratório.

## Regras modeladas

- Aluno pode se matricular em até 4 disciplinas obrigatórias.
- Aluno pode selecionar até 2 disciplinas optativas.
- Disciplina precisa de pelo menos 3 alunos para ficar ativa.
- Disciplina comporta no máximo 60 alunos.
- Matrícula e cancelamento só devem ocorrer dentro do período de matrícula.
- Sistema de cobranças deve ser notificado após matrícula.
- Professores podem consultar alunos matriculados em suas disciplinas.
- Todos os usuários possuem senha para validação de login.

## Pacotes Java

- `model`: entidades principais do sistema.
- `service`: serviços responsáveis pelos casos de uso.
- `integracao`: contrato com o sistema de cobranças.
- `exception`: exceções específicas do domínio.
